# OpsPilot Roadmap

## Quarterly Roadmap
### Q1 (Implemented)
- Auth, project lifecycle, incident lifecycle, comment workflow.
- Audit logging and dashboard summary endpoints.
- Frontend dashboards for projects and incidents.

### Q2 (Future Architecture)
- Resource inventory and discovery control plane.
- Monitoring ingestion foundations (metrics/logs/traces).

### Q3 (Future Architecture)
- Alert correlation and incident automation.
- Role-based access controls and team hierarchy.

### Q4 (Future Architecture)
- AI assistant with RAG and RCA workflows.
- Remediation recommendations and runbook automation.

## Priorities
1. Data-plane completeness (resource + telemetry ingestion).
2. Operational automation (alert -> incident pathways).
3. AI grounding quality and trust controls.

## Milestones
- M1: Discovery MVP.
- M2: Monitoring MVP.
- M3: Alert/Incident automation MVP.
- M4: AI assistant beta.

## Future Vision
Make OpsPilot the execution layer for engineering operations, where every incident can be explained, traced, and resolved faster with trustworthy AI assistance.
