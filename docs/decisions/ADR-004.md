# ADR-004: AutoMigrate for MVP Schema Evolution

## Decision
Use GORM `AutoMigrate` during application startup for current schema evolution.

## Reason
Reduces operational overhead during early product iteration and accelerates model evolution.

## Alternatives Considered
- Versioned SQL migration framework from day one.
- Manual DDL management.

## Tradeoffs
- Simpler early-stage delivery.
- Lower migration determinism and rollback control; requires future migration system.

## Status
Accepted for MVP, planned replacement in Future Architecture.
