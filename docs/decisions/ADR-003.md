# ADR-003: React Query + Service Layer in Frontend

## Decision
Use React Query for server-state and a dedicated typed service layer for all HTTP calls.

## Reason
Centralizes network behavior, cache policies, and mutation invalidation patterns while keeping components focused on rendering.

## Alternatives Considered
- Direct axios calls in components.
- Global Redux for all state.

## Tradeoffs
- Additional abstraction layers and query key management.
- Better data consistency, retry behavior, and maintainable feature growth.

## Status
Accepted and implemented.
