# ADR-002: JWT + Ownership Authorization Model

## Decision
Use JWT bearer authentication with service-layer ownership checks as the authorization baseline.

## Reason
Fast to implement for MVP while preserving access boundaries around project and incident data.

## Alternatives Considered
- Session-based auth.
- Early RBAC with roles and team policies.

## Tradeoffs
- Simpler rollout and lower complexity now.
- Limited flexibility for cross-team workflows; requires future RBAC migration.

## Status
Accepted and implemented.
